Stash Privacy Policy

Last updated: August 24, 2026

Stash is a clipboard history and snippet utility for iOS, iPadOS, and macOS. This Privacy Policy explains what Stash stores, what may be synchronized, and what remains on a device.

Data Stored by Stash

Stash stores the clipboard content that the user chooses to keep, including history items, snippets, favorites, text, rich text, images, file references, folders, multiple-copy groups, and media metadata. Clipboard content is stored locally on the user's device by default.

On macOS, the optional automatic clipboard saving switch is a per-device setting. When it is off, Stash ignores newly copied items for automatic history saving. Explicit actions such as saving a snippet or choosing a copy/save action remain user-controlled.

What Is Stored

The exact storage behavior depends on the platform and the item type. Stash intentionally separates the following categories:

1. Original content stored in Stash

Some text, rich text, images, videos, audio, and imported file content are retained in the app's local storage according to the platform's size and type rules. When a stored body is eligible for iCloud sync, its supported payload may also be synchronized.

2. Original content stored locally but not synchronized

Some large or platform-specific bodies are kept only on the device where they were captured. They are not uploaded to CloudKit. The item can still be used on that device while its local data is available.

3. Reference metadata only

For many files, folders, packages, archives, media, fonts, office/iWork documents, code files, and other items, Stash keeps metadata rather than copying the original body. This can include a display name, extension, Uniform Type Identifier, source application or device, original file URL, and security-scoped access information when available. The original file or folder remains outside Stash.

Whether an item is stored as content or metadata is decided per clipboard item. The same extension can be classified differently when the source provides text, an image, or a file reference.

The byte count shown in a preview is the stored body size for content saved in Stash. For metadata-only items, it is the size of the metadata record, not the size of the original file.

iCloud Sync

If iCloud sync is enabled, eligible data is stored in the user's private CloudKit database associated with their Apple Account. Stash uses the user's private iCloud account and does not send clipboard content to an independent Stash server.

History items that contain only local file or folder access information do not upload the original file or folder body. Such an item may appear on another device as metadata, but the original local file may not be available there. Device-only unlock information and local security-scoped access are not synchronized.

Sync settings are controlled per device. A Mac with automatic clipboard saving disabled does not automatically save new copies on that Mac; this does not turn off sync or delete existing synchronized items on another device.

Sensitive Snippets

Sensitive snippets are encrypted before being stored and are protected by the app's authentication flow. They are hidden from ordinary lists and preview cards to reduce accidental exposure. This feature is not a replacement for a dedicated password manager.

Passwords, derived encryption keys, and device-only unlock information are not synchronized as ordinary clipboard data. The user is responsible for deciding what sensitive information to save in Stash.

Analytics and Tracking

Stash does not include analytics, advertising, telemetry, or third-party tracking code.

Data Sharing

Stash does not sell user data and does not share clipboard data with third parties. Data is transmitted only when the user uses an operating-system sharing or pasteboard workflow, or when the user enables the app's iCloud synchronization.

User Control and Deletion

Users can delete history items, snippets, favorites, and stored data from within the app. Deleting a Stash item removes Stash's copy or metadata record and any supported synchronization record; it does not delete the original file or folder from the user's device or Finder.

Temporary export files used to provide file paste are cleaned up according to the platform's temporary-file lifecycle. The original source remains under the control of the operating system or the source application.

For privacy questions or support requests, please contact output@unwraps.net.

Stash プライバシーポリシー

最終更新日: 2026年8月24日

Stashは、iOS、iPadOS、macOS向けのクリップボード履歴・スニペット管理アプリです。このプライバシーポリシーでは、Stashが保存するデータ、同期されるデータ、端末内に留まるデータを説明します。

Stashが保存するデータ

Stashは、ユーザーが保存することを選択したクリップボード履歴、スニペット、お気に入り、テキスト、リッチテキスト、画像、ファイル参照、フォルダ、複数コピー、メディアのメタデータなどを扱います。クリップボードの内容は、標準ではユーザーの端末にローカル保存されます。

macOSでは、自動保存スイッチは端末ごとの設定です。オフにすると、新しくコピーした項目は自動的な履歴保存の対象になりません。スニペット保存など、ユーザーが明示的に行う操作は引き続き利用できます。

保存されるもの

保存方法は、プラットフォームと項目の種類によって異なります。Stashでは、次の3つを区別しています。

1. Stash内に本体が保存されるもの

一部のテキスト、リッチテキスト、画像、動画、音声、読み込んだファイル本体は、プラットフォームごとのサイズ・種類のルールに従ってアプリ内に保存されます。本体保存されたデータのうち同期対象になるものは、対応するペイロードがiCloudにも同期されます。

2. 本体は端末内に保存されるが、同期されないもの

大きなデータやプラットフォーム固有の本体データの一部は、取得した端末だけに保存されます。CloudKitにはアップロードされません。端末内のデータが利用可能な間は、その端末で使用できます。

3. 本体ではなく参照メタデータだけが保存されるもの

多くのファイル、フォルダ、パッケージ、アーカイブ、メディア、フォント、Office/iWork書類、コードファイルなどでは、元の本体をコピーせず、メタデータを保持します。表示名、拡張子、Uniform Type Identifier、コピー元アプリや端末、元ファイルURL、取得できる場合はセキュリティスコープ付きアクセス情報などが含まれます。元ファイルや元フォルダはStashの外部に残ります。

本体保存かメタデータのみかは、クリップボード項目ごとに判定されます。同じ拡張子でも、コピー元がテキスト、画像、ファイル参照のどれを提供したかによって分類が変わる場合があります。

プレビューに表示されるバイト数は、Stash内に本体を保存している項目では保存された本体のサイズです。メタデータのみの項目では、元ファイルのサイズではなくメタデータ記録自体のサイズです。

iCloud同期

iCloud同期を有効にすると、同期対象のデータはユーザーのApple Accountに紐づくプライベートCloudKitデータベースに保存されます。Stashはユーザー自身のプライベートiCloudを使用し、独自のStashサーバーへクリップボード内容を送信しません。

ファイルやフォルダへのローカルアクセス情報だけを持つ履歴では、元ファイルや元フォルダの本体はアップロードされません。そのため、別端末にはメタデータが表示されても、元のローカルファイルをその端末で利用できない場合があります。端末専用のロック解除情報やローカルのセキュリティスコープ付きアクセス情報も同期されません。

同期設定は端末ごとに管理されます。あるMacで自動保存をオフにしても、そのMacで新しくコピーした項目の自動保存が止まるだけで、別端末にある既存の同期項目がオフになったり削除されたりすることはありません。

秘密スニペット

秘密スニペットは保存前に暗号化され、アプリの認証フローで保護されます。意図しない露出を減らすため、通常の一覧やプレビューカードには表示されません。この機能は専用のパスワードマネージャーの代替ではありません。

パスワード、暗号化キーを導出する情報、端末専用のロック解除情報は、通常のクリップボードデータとして同期されません。Stashにどのような機密情報を保存するかは、ユーザー自身の判断と責任で行ってください。

解析・トラッキング

Stashには、解析、広告、テレメトリ、第三者トラッキングのコードは含まれていません。

データの共有

Stashはユーザーデータを販売せず、クリップボードデータを第三者と共有しません。データが外部へ渡るのは、ユーザーがOSの共有・ペーストボード機能を使った場合、またはiCloud同期を有効にした場合です。

ユーザーによる管理と削除

ユーザーは、アプリ内から履歴、スニペット、お気に入り、保存データを削除できます。Stashの項目を削除すると、Stash内の本体またはメタデータ記録と、対応する同期記録が削除されますが、端末上またはFinder上の元ファイルや元フォルダは削除されません。

ファイルとしてペーストするために使われる一時書き出しファイルは、プラットフォームの一時ファイルのライフサイクルに従って整理されます。元データは、OSまたはコピー元アプリの管理下に残ります。
