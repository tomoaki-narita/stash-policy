Stash Privacy Policy

Last updated: August 3, 2026

Stash is a clipboard history and snippet utility for iOS, iPadOS, and macOS. This Privacy Policy explains how Stash handles data.

Data Stored by Stash

Stash stores clipboard history, snippets, favorites, text, rich text, images, files, folders, audio, and local videos so they can be reused by the user.

By default, clipboard data is stored locally on the user's device.

iCloud Sync

If iCloud sync is enabled, syncable data is stored in the user's private CloudKit database associated with their Apple Account.

Some data is intentionally kept local, including original local file access data, security-scoped file access information, local video files, and device-only unlock information.

Sensitive Snippets

Sensitive snippets are encrypted before being stored and are hidden in lists and preview cards. They are intended to reduce accidental exposure, not to replace a dedicated password manager.

The user is responsible for deciding what sensitive information to save in Stash.

Analytics and Tracking

Stash does not include analytics, advertising, telemetry, or third-party tracking code.

Data Sharing

Stash does not sell user data and does not share clipboard data with third parties.

User Control

Users can delete history items, snippets, and stored data from within the app. Deleting a history item removes it from Stash's history, but it does not delete the original file or folder from the user's device or Finder.

Contact

For privacy questions or support requests, please contact: output@unwraps.net

Stash プライバシーポリシー

最終更新日: 2026年8月3日

Stashは、iOS、iPadOS、macOS向けのクリップボード履歴・スニペット管理アプリです。 このプライバシーポリシーでは、Stashがデータをどのように扱うかを説明します。

Stashが保存するデータ

Stashは、ユーザーが再利用できるように、クリップボード履歴、スニペット、 お気に入り、テキスト、リッチテキスト、画像、ファイル、フォルダ、音声、 ローカル動画を保存します。

標準では、クリップボードデータはユーザーの端末上にローカル保存されます。

iCloud同期

iCloud同期を有効にした場合、同期対象のデータはユーザーのApple Accountに紐づく プライベートCloudKitデータベースに保存されます。

元ファイルへのローカルアクセス情報、セキュリティスコープ付きアクセス情報、 ローカル動画ファイル、端末専用のロック解除情報など、一部のデータは意図的に ローカルのみに保持されます。

秘密スニペット

秘密スニペットは保存前に暗号化され、一覧やプレビューカードでは非表示になります。 この機能は意図しない露出を減らすためのものであり、専用のパスワードマネージャーの 代替ではありません。

Stashにどのような機密情報を保存するかは、ユーザー自身の判断と責任で行ってください。

解析・トラッキング

Stashには、解析、広告、テレメトリ、第三者トラッキングのコードは含まれていません。

データの共有

Stashはユーザーデータを販売せず、クリップボードデータを第三者と共有しません。

ユーザーによる管理

ユーザーは、アプリ内から履歴、スニペット、保存データを削除できます。 履歴項目を削除するとStash内の履歴から削除されますが、端末上またはFinder上の 元ファイルや元フォルダは削除されません。
